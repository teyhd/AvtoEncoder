# Encoder experiments

Legacy Keras/TensorFlow scripts for image autoencoder and GAN training, loading and generation. These are an additional source component; the repository's existing source is preserved.

Use a separate environment and `requirements.txt` as an import inventory; exact original dependency versions are unknown. Provision authorized local image inputs and pretrained weights separately and adjust the scripts' local paths before executing. These research scripts can start training immediately when imported/run. Syntax and secret checks passed; training, model loading and generated-image quality were not tested. No images, weights, logs or outputs are included.
